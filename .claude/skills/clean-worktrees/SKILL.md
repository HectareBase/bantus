# ワークツリーの片付け

一覧と削除は `tools/clean-worktrees.ps1` が行う。どのワークツリーをどのセッションが使っているかはスクリプトでは分からないので、セッションの一覧と突き合わせるのはこのスキルの役目。**消すのは、ユーザーが選んだものだけ**。

## 1. 一覧を作る
```bash
powershell -NoProfile -File tools/clean-worktrees.ps1 -Json
```
項目：`name`（フォルダ名）、`kind`（`worktree` / `orphan`＝git の登録がなくフォルダだけ / `prunable`＝登録だけ）、`branch`、`dirty`（未コミットの件数）、`ahead`（main にないコミットの数）、`atBase`（main と同じ＝コミットがまだない）、`current`（今いるワークツリー）、`sizeMB`。

あわせて `mcp__ccd_session_mgmt__list_sessions` を `include_archived: true`、`limit: 100` で呼び、各セッションの `cwd` とワークツリーの `path` を突き合わせる（大文字小文字と `\` `/` の違いは無視する）。

## 2. 分ける
| 分類 | 条件 | 扱い |
|---|---|---|
| 残す | セッションが実行中（`isRunning`）、`current`、または `atBase` で最近作られたもの | 選択肢に出さない。残す理由を一言添える |
| 注意 | `dirty` か `ahead` がある | 選択肢には出すが、何が失われるかを書く。選ばれたら `-Force` が要ると伝え、もう一度確かめる |
| 消してよい | 上のどれでもない | 選択肢に出す |

`ahead` があっても、スカッシュマージで取り込まれていて実は不要なことがある。分からなければ、ブランチの最後のコミットの要約を見せて判断を任せる。

## 3. ユーザーに選んでもらう
`AskUserQuestion` で 2 つ聞く。
- どれを消すか（`multiSelect: true`）。各選択肢に大きさと、使っているセッションのタイトル（アーカイブ済みか）を書く
- main に取り込み済みのブランチも消すか（推奨は状況次第。消してもセッションの会話は残るが、再開してもブランチは戻らない）

## 4. 消す
選ばれたもののうち、**アーカイブされていないセッションが使っているもの**は、先にユーザーの了承を得てそのセッションを `mcp__ccd_session_mgmt__archive_session` でアーカイブする。アーカイブするとアプリがワークツリーを片付ける。アーカイブせずにスクリプトで消すと、中身は消えてもフォルダが「使用中」で残る。

残りはスクリプトで消す。
```bash
powershell -NoProfile -File tools/clean-worktrees.ps1 -Remove <名前1>,<名前2>
```
ブランチも消すなら、同じ呼び出しに `-DeleteMergedBranches` を付ける。どこかのワークツリーで使っているブランチと、main に取り込まれていないブランチは残る。

結果の印：`○` 削除した、`△` フォルダが使用中で残った（使っているセッションをアーカイブすると消える）、`×` 消さなかった（理由つき）。

## 5. 確かめて報告する
もう一度 `tools/clean-worktrees.ps1` を動かし、残ったものを確かめる。報告には、消したもの（合計の大きさ）、消したブランチ、残したものとその理由を書く。

## 守ること
- `mcp__ccd_host__clean_up_worktrees` は 30 日以上使っていないものしか対象にしないので、ここでは使わない
- セッションの削除（`delete_session`）はしない。頼まれてもアーカイブを勧める
- 実行中のセッションのワークツリーは、選ばれても消さない
