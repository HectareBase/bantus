# コミットメッセージの決まり

日本語で書き、1 行目に変更の種別を付けます。形は [Conventional Commits](https://www.conventionalcommits.org/ja/v1.0.0/) に合わせ、種別と範囲は英語、要約は日本語にします。`.githooks/commit-msg` が検査し、合わなければコミットを止めます。

## 形
```
<種別>(<範囲>): <日本語の要約>

<本文（任意）>
```
- 1 行目の後は、1 行空けてから本文を書く（空けないと、git は全体を題名として扱う）
- 範囲は付けられるときだけ付ける。2 つ以上にまたがるときは省く
- 要約は「〜する」「〜を直す」のように、何をしたかを短く書く。文末に句点は付けない
- 前と互換のない変更は、種別の後に `!` を付ける（`feat(app)!: …`）
- 本文には、変えたことを箇条書きで書く。理由や、選ばなかった方法もここに書く

## 種別
| 種別 | 使うとき |
|---|---|
| `feat` | できることが増えた、見た目や動きが変わった |
| `fix` | 不具合を直した |
| `docs` | 文書だけを変えた |
| `refactor` | 動きを変えずにコードを整理した |
| `perf` | 速くした、軽くした |
| `test` | テストだけを足した、直した |
| `style` | 書式だけを変えた（空白、並び） |
| `build` | ビルド、依存するパッケージ |
| `ci` | CI の設定 |
| `chore` | そのほか（フック、設定ファイルなど） |
| `revert` | 前のコミットを取り消した |

## 範囲
| 範囲 | フォルダ |
|---|---|
| `app` | `app/`（Electron 版のウィジェット） |
| `tools` | `tools/`（検証用のスクリプト） |
| `docs` | `docs/` |
| `hooks` | `.githooks/` |

## 例
```
feat(app): ツールチップを自前で描く

- title 属性を data-tip に変え、popover="hint" のツールチップ 1 つを使い回す
- たたんだ表示は幅が足りないので、OS のツールチップのままにする
```
```
fix(app): ツールチップが消えるときに上部へ飛ぶのを直す
```
```
docs: コミットメッセージの決まりを書く
```

## 検査しないもの
`git merge` と `git revert` が作るメッセージ（`Merge …`、`Revert "…"`）、`fixup!` と `squash!` から始まるものは、そのまま通します。

決まりを変えるときは、この文書と `.githooks/check-commit-msg.sh` の種別と範囲の一覧をそろえます。
