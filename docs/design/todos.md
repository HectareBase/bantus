# プロジェクトの ToDo

プロジェクト（リポジトリの盆）ごとに、短いやることの一覧を持つ。セッションを始めるほどではない思いつきや、作業の順番のメモを、そのプロジェクトのカードのすぐ上に置いておく。Bantus の中だけのもので、Claude のデータには書かない。

## 見た目と動き
- プロジェクトの見出しの、名前のすぐ右に「ToDo を足す」ボタン（チェックの付いたリストに＋のアイコン、14px）。ふだんは薄く（不透明度 0.55）、見出しに乗せると濃くする
- ToDo が 1 件以上あるとき、見出しとワークツリーのカードの間にチェックリストを出す。0 件なら何も出さない。行の高さは 22px、枠の余白は 2px だけ
- ボタンを押すと、リストの一番下に入力欄を開く
  - Enter で確定し、続けて次を入力できる。Esc か、空のまま外を押すとやめる。文字があるまま外を押したときは足す
  - 日本語の変換中の Enter は確定にしない
- 文字を押す（キーボードでは Enter か F2）と書き直せる。空にすると消える
- 行に乗せると × が出て、すぐ消せる
- チェックすると、緑のチェックと左から引く打ち消し線にして、行の下の細い線を 2.5 秒かけて縮める。縮みきったら薄くして高さを詰めて消え、データからも消す。その間にもう一度押すと取り消し
- 5 件以上で畳む。最初の 3 件と「ほか N 件」のボタンを出し、押すと全部開いて一番下が「畳む」になる。畳んでいるときに足すボタンを押したら、開いてから入力欄を出す

## アニメーション
- 打ち消し線とチェックの印は transform と opacity、残り時間の線は transform（scaleX）で動かす
- 高さを詰めるのだけは height の transition（消えるときに一度だけ）
- ひかえめ（`data-motion="subtle"`。動きを減らす OS の設定でも付く）のときは、線を引く・縮める・詰める動きをやめ、チェックしたらすぐ済みの見た目にする。消えるまでの時間は同じ

## 作り
| ファイル | 中身 |
|---|---|
| `app/src/shared/todos.ts` | 形（`TodoItem`、`TodoStore`）、そろえ方、畳む件数の判定（`todoFold`）、件数・時間の定数 |
| `app/src/main/todo-store.ts` | `todos.json` の読み書き。一時ファイルに書いてから置き換え、読めないファイルは `todos.json.bad` に移す |
| `app/src/renderer/todo.ts` | リストの部品。行を描き、入力・チェック・畳むを扱う |
| `app/src/renderer/renderer.ts` | 見出しを作るときに部品をつなぎ、起動時に読んだ中身を渡す |

- 保存先は `settings.json` と同じフォルダの `todos.json`。プロジェクトの目印（`RepoView.key`。リポジトリのフォルダのパスをそろえたもの）をキーに、`{ id, text }` の並びを持つ。空になったプロジェクトはキーごと消す
- 画面は起動時に `todos:get` で全部を読み、変えるたびに `todos:set` で 1 つのプロジェクトの並びを丸ごと送る。メインプロセスがそろえて（文字は 120 文字まで、1 プロジェクト 200 件まで）書く。受け取るのはウィジェットの画面からだけ
- 入力欄を開いている間は、保留のメモと同じく、行やカードを並べ替えない（並べ替えるとフォーカスが外れる）。ToDo のリストもその間は作り直さず、消えた行だけをその場で外す
- チェックした状態は保存しない。消える前にウィジェットを閉じたら、チェックしていない ToDo として残る

## 見本データ
`app/fixtures/*.json` の項目に `"todos": ["…", "…"]` を書くと、その項目のプロジェクトの ToDo になる（同じプロジェクトでは最初に書いたもの）。`all-states.json` では、畳まないプロジェクト（3 件）と畳むプロジェクト（6 件）に入れている。見本のデータフォルダに `todos.json` がまだないときだけ入れるので、もう一度見本から始めるときはそのファイルを消す。
