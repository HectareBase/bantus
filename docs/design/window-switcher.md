# ウィンドウの切り替え

ウィジェットと同じモニターにある、Claude 以外のウィンドウのアイコンをウィジェットの一番下に並べ、押すとそのウィンドウを前に出します。Claude のウィンドウの後ろに隠れたウィンドウを、Alt+Tab を使わずに前に出すためのものです。セッションを並べるのがウィジェットの役割なので、場所は 1 列の帯だけにします。

## 画面
- ウィジェットの一番下（HTML ビューアがあればその下）に、高さ 28px の帯を 1 本置く。中に 16px のアイコン（ボタンは 24px）を横に並べる
- ウィンドウごとに 1 つ（アプリごとに 1 つにはまとめない）。見分けはツールチップのウィンドウのタイトル
- 並び順はタスクバーに近づける。同じアプリ（実行ファイル）のウィンドウを隣り合わせにし、アプリは起動した順（そのアプリの一番古いプロセス）、アプリの中はプロセスの起動順、同じプロセスの中はハンドルの順。手前の順（`EnumWindows` の順）は使わない。押して前後が入れ替わるたびにアイコンの位置が動き、どこに何があるか覚えられなかったため
- 前面・後ろ・最小化はタスクバーと同じ見せ方にする。色は状態だけを表すので、状態の色は使わない
  - 今前面にあるウィンドウ（前面のウィンドウか、その持ち主）：塗りと長い下線。ツールチップに「前面にあります」
  - ほかのウィンドウの後ろにあるもの：短く薄い下線。ツールチップに「ほかのウィンドウの後ろにあります」
  - 最小化しているもの：下線なしで、アイコンを薄くする。ツールチップに「最小化しています」。押すと元に戻して前に出す
  - 前面の印は 3 秒おきの取得で変わる。帯から前に出したときと、マウスをウィジェットに乗せたときはすぐ変わる
- 入りきらない分は「+N」にまとめる。押すと、帯の上に残りの一覧（アイコンとタイトル）を開く。外を押す、Esc、ウィジェットからフォーカスが外れると閉じる
- ウィンドウが 1 つもないとき、設定でオフのときは、帯ごと消す
- 動きは付けない。届いた一覧と前の一覧の違うところだけを書き換える

### 残りの一覧をウィジェットの中に開く理由
めくれやツールチップと同じく別のウィンドウに出す案もありましたが、ウィジェットの中（帯の上）に重ねる形にしました。
- 一覧はめったに開かないので、そのための窓を常に用意しておく（めくれの窓のように出したままにして、カーソルを見続ける）のは割に合わない
- 帯の上にはカードの一覧があり、重ねても困らない。幅もウィジェットと同じで足りる

HTML ビューアの HTML は別のビュー（WebContentsView）で画面の一番上に重なるので、一覧を開いている間だけビューアの HTML を引っ込める（`viewer.ts` の `setCovered`）。

## 並べるもの
`EnumWindows` で見て、Alt+Tab に出るものだけを残す。
- 見えている（`IsWindowVisible`）、タイトルがある
- ツールウィンドウ（`WS_EX_TOOLWINDOW`）でない
- `WS_EX_APPWINDOW` が付いているか、所有者がなく `WS_EX_NOACTIVATE` でもない
- DWM で隠されていない（`DWMWA_CLOAKED` が 0。ほかの仮想デスクトップや、裏で待っているストアアプリを除く）
- ウィジェットと同じモニター（`MonitorFromWindow`）。最小化したウィンドウは画面の外にあるので、元に戻したときの場所（`GetWindowPlacement`）で決める
- Claude（実行ファイル名が `claude`）と Bantus 自身のプロセスを除く
- 多くても 60 個まで

## 作り
| 部分 | ファイル | 内容 |
|---|---|---|
| 列挙と前に出す | `app/src/main/foreground.ts` | 常駐の PowerShell（前面のウィンドウを調べるのと同じもの）に `wins` と `front` の命令を足した。新しいプロセスは増やさない。列挙は C# でまとめて行い、1 行で答える（パスとタイトルは base64） |
| 取得の間隔 | `app/src/main/window-switcher.ts` | タイマーは 1 つ。ウィジェットが見えていて設定がオンの間だけ 3 秒おきに調べ、マウスがウィジェットに入ったときにもすぐ調べる。前の一覧と同じなら画面に送らない。PowerShell が答えないときは空の一覧として帯を消すだけで、ほかの機能は止めない |
| アイコン | 同上と `main.ts`、`foreground.ts` の `icon` の命令 | タスクバーや Alt+Tab と同じ、ウィンドウ自身のアイコンを使う（`WM_GETICON`、なければウィンドウのクラスのアイコン。PowerShell が PNG の base64 で答える）。取れないときだけ `app.getFileIcon` で実行ファイルのアイコンにする。ウィンドウごとに 1 回だけ取り、同じ絵は 1 つにまとめて画面に 1 回だけ送る。拡大して出すとき（Windows の拡大率と表示の拡大率の積が 1 より大きい）は 32px のものを先に探す |
| 画面 | `app/src/renderer/switcher.ts`、`index.html`、`styles.css` | 帯と残りの一覧。入る数は `app/src/shared/switcher-fit.ts` |
| 設定 | `app/src/shared/settings.ts` | 一般 → ウィンドウの切り替え →「ウィンドウのアイコンを表示する」（初期値はオン）。オフならタイマーも止める |

`index.html` の CSP に `img-src 'self' data:` を足した（アイコンを data URL で出すため）。

前に出すときは、画面から届いたハンドルが最後に送った一覧にあるかを確かめてから、PowerShell に渡す。最小化なら `ShowWindow`（元に戻す）、`SetForegroundWindow` を呼び、断られたら Claude を前に出すときと同じく、使われていない仮想キー（0x88）を押して離してからもう一度呼ぶ。ハンドルがもう無効なら何もしない。

## 負荷
- PowerShell への問い合わせは 1 回 1 ms ほど（20 回の平均。ウィンドウ 5 個）。3 秒おきなので、PowerShell の CPU は 90 秒で 0.03 秒ほど
- Electron 側の CPU は、オンとオフで見分けられる差はなかった（セッションの行のアニメーションによる揺れのほうが大きい）

## 確かめたこと
- 同じモニターのウィンドウのアイコンが、アプリごと・起動した順に並ぶ。押しても位置は変わらない。Claude と Bantus 自身は出ない
- アイコンはタスクバーと同じ絵になる（実行ファイルのアイコンでは、汎用のアイコンになるアプリがあった）
- 前面のウィンドウに塗りと長い下線が付き、押したウィンドウへ移る
- Claude の後ろにあるウィンドウを押すと前に出る。最小化したものは元に戻る
- 帯が狭いと「+N」にまとまり、押すと残りの一覧が開く。HTML ビューアを出していても一覧が隠れない
- 設定をオフにすると帯が消え、PowerShell への問い合わせも止まる

まだ確かめていないこと：モニターが 2 台のときに、別のモニターのウィンドウが出ないこと（モニターが 1 台の環境でしか動かしていない）。
