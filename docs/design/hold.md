# 保留（あとで再開するセッションとワークツリー）

ほかの作業を先に進めるために、いったん手を止めたセッションやワークツリーに「保留」の印を付ける。アーカイブと違って画面から隠さず、ピンクの印と理由のメモで「あとで戻る」ことがわかるようにする。この文書は作る前の実装イメージ（見本は `local/mockups/hold.html`、手元専用）。

## ねらい
- 今のアーカイブは「使い終わったもの」を隠すためのもの。待機中のまま置いておくと、ワークツリーは新しいセッションに押されて、main は時間で、自動でアーカイブされてしまう
- 「別の作業がマージされるまで待つ」「レビューの返事待ち」など、**自分の都合で止めている**ものを、待機中（Claude の番が終わった）とは別の状態として見分けたい
- 止めた理由は時間がたつと忘れるので、短いメモを残す

### 考え方
- 保留は Bantus の中だけの印（アーカイブと同じく `settings.json` に入れる）。Claude のデータには書かない
- **保留したものは隠さない**。どの自動の決まりでもアーカイブしない
- **動き出したら保留を外す**。保留を外し忘れて、動いているのにピンクのまま、ということがないようにする
- 色は状態だけを表す、という今の決まりに合わせ、保留を 5 つめの「状態の色」として扱う

## 何に付けるか
| 対象 | 使う場面 | 印の置き場所 |
|---|---|---|
| セッション（行） | 1 つの会話を止めておく。main の質問など | 行の状態のアイコンと、2 行目 |
| ワークツリー（カード） | ブランチごと作業を止めておく。中のセッションは入れ替わってもよい | カードの見出しと、見出しのすぐ下のメモの段 |

カードを保留すると、中の行には印を付けない（見出しだけで分かる）。カードの保留と行の保留は別々に持ち、両方付けてもよい。

## 見た目
- 色は `--held`（既定 `#e05aa8`、今の色の候補にあるピンク）。設定の「状態の色」に「保留」の行を足し、ほかの状態と同じく変えられる
- **行**
  - 状態のアイコンを `circle-pause`（ピンク）にする。待機中の印は出さない（保留が待機中を上書きする）
  - 状態の文字（`showState`）は、保留してからの経過を付けた「保留 2 日」（`heldLabel`。分・時間・日の 1 つの単位で、1 分ごとの描き直しで進む）。保留して 1 分たつまでは「保留」とだけ出す（「保留したばかり」は長く、狭い幅でメモの枠を押し出すため）。薄いピンクの背景（`--held-bg`）
  - 「保留」の文字の右に、**メモの枠**（ピンクの細い枠で囲った箱）を置く。メモが空なら枠の中はペン（`pencil`）のアイコンだけ。メモがあれば、ペンは出さずにメモだけを 1 行で出す（行の右端まで。はみ出す分は `…`）。入力中もペンは出さない（枠の中は入力欄だけ）。ペンは「まだ何も書いていない」印として、空のときだけ出す
  - 「◯分前」は出さない（2 行目をメモに使うため）。代わりに、保留してからの経過を状態の文字に入れる
  - ツールチップにはメモの全文と、保留した時刻からの経過（「保留 2 日」。1 分たつまでは「保留したばかり」）を出す
  - 背景は塗らない（今開いている行のストライプとぶつけないため）。左端の帯（未確認）はそのまま
- **カード**
  - 見出しのブランチ名の左のアイコン（`git-branch`／家）をピンクの `circle-pause` に替え、見出しの帯をごく薄いピンク（`--held-bg` を見出しの濃さで）にする
  - 見出しの 2 段目に、行と同じ「保留 2 日」の文字とメモの枠を置く（見出しの高さは保留の間だけ 1 段増える）
  - 中の行は少し薄く（不透明度 0.7）して、止めていることを伝える。乗せると元の濃さ
- **リポジトリの見出しのバッジ**：対応待ち・処理中がないときだけ「保留 n」をピンクで出す（急ぐものを優先する今の決まりのまま）
- **一覧（めくれ）**：アーカイブした行のうち保留はない（保留は隠さないため）。タイムラインで今出ている行として描くときは、行と同じアイコンにする

## 操作
ボタンは増やさない。行の右端のボタンは今のアーカイブだけのまま（保留中の行とカードでは出さない。保留とアーカイブは同時に付けない）。

### 保留の切り替え：状態のアイコンを押す
- 行の状態のアイコン（カードは見出しのアイコン）を押すと、保留にする・外すを切り替える。行のほかの所を押したときは今と同じくセッションを開く（アイコンの押下は行へ伝えない）
- 押せることがわかるよう、乗せたときだけアイコンを変える
  - 待機・停止の行：アイコンをピンクの `circle-pause`（薄め）に替え、丸い背景を付ける。ツールチップは「保留する」
  - 保留の行：アイコンを `circle-play` に替える。ツールチップは「保留を外す」
  - 処理中・対応待ちの行：アイコンは変えず、押しても何もしない（動いているものは保留にしない）。そうした行のあるカードの見出しのアイコンも同じ
- 押す的は、アイコンの 16px より広く、行の高さいっぱい・幅 28px ほどにする（行を開くつもりで押し間違えにくいよう、乗せたときの見た目の変化をはっきりさせる）
- 保留にしたら、そのままメモの枠を入力の状態にする（すぐ理由を書ける。書かずに外を押せば、メモなしで保留のまま）
- 押し間違えて外したときに困らないよう、外したメモはウィジェットの中だけで覚えておき、同じ行（カード）をもう一度保留にしたら戻す（保存はしない。ウィジェットを閉じたら忘れる）

### メモ：ペンの枠がそのまま入力欄になる（入力中と、メモがあるときはペンを出さない）
- メモの枠を押すと、枠がその場で入力欄に変わる（別の欄やボタンは出さない）
  - 枠の幅は、入力した文字に合わせて右へ広がる。行の右端まで来たら折り返し、行の高さが増える（`textarea` の高さを中身に合わせる）
  - Enter とフォーカスが外れたとき（外を押した、ほかのアプリへ移った）に確定する。Esc は入力をやめて元のメモに戻す
  - **日本語の入力中（変換中）の Enter では確定しない**（`compositionstart`〜`compositionend` の間と `isComposing` の Enter は見送る）
  - 改行は入れない（貼り付けた改行は空白に替える）。200 文字まで。前後の空白は除き、空にして確定したらペンだけの枠に戻る（保留は外さない）
  - 入力中は、そのカードの描き直しで入力欄を作り直さない（状態が変わっても、入力が終わるまで行の位置を保つ）
- ウィジェットのウィンドウはフォーカスを取れるので、別のウィンドウは作らず、ウィジェットの中に描く
- メモの枠を押しても、セッションは開かない
- 右クリックのメニューは作らない（今の作りに右クリックの操作がないため）

### 保留を外す
1. 状態のアイコンを押す
2. **動き出したとき**：保留の行が処理中・対応待ちになったら印を外す（手でアーカイブしたものが動き出したときと同じ）。カードは、中のどれかのセッションが動き出したら外す。保留を外したときはメモも消す
   - 外したあとは、今の「戻ったもの」と同じ猶予（main の自動アーカイブと同じ時間）で、落ち着いてもすぐにはアーカイブしない
3. **セッションが消えたとき**（デスクトップで消した）は印も消す。カードは、中のセッションがすべてなくなったら消す

保留の行を押して開くだけ（読むだけ）では外さない。

## アーカイブの決まりとの関係
[worktree-cards.md](worktree-cards.md) の「アーカイブの決まり」の 1 の次に、次の決まりを足す。

- **保留したものは出す**：保留の行は、ワークツリーの「一番新しいもの以外」にも、main の時間にもかからない。保留のカードは、マージ済みでもカードごと隠さない（マージ済みの印は今と同じく出す）
- 保留の行が main の起点（ワークツリーを作った元）でも、ワークツリーのカードへは移さず main に出す
- 保留するときに付いていたアーカイブの印（手で戻した `shown` など）は消す。保留を外したら自動の決まりに戻る

## 並び順と巡回
- 並び順の「優先度」では、対応待ち → 処理中 → 待機（停止中と中断を含む）→ **保留**（今は戻らないと決めたもの）。「固定」「更新日時」では今のまま
- `Ctrl+Alt+N` の巡回からは外す（今は戻らないと決めたものなので）。未確認の帯があるときは、帯のほうを優先して巡回に入れる
- 通知：保留の行は「完了したとき」の通知を出さない。動き出して保留が外れたあとは、ふつうの行と同じ

## 保存する形
`Settings` に 2 つ足す（どちらも設定画面には出さない）。

```ts
/** 保留の印。note は理由のメモ（空でもよい）、since は保留にした時刻（Unix ミリ秒） */
export interface HoldMark { note: string; since: number }

/** セッションの ID → 保留の印 */
holds: Record<string, HoldMark>;
/** カードの目印 → 保留の印 */
heldCards: Record<string, HoldMark>;
```

- 読み込むときは、`SESSION_KEY_ID`／`isCardKey` に合う目印と、文字列の `note`（制御文字を除き 200 文字まで）、有限の `since` だけを残す（`normalizeMarks` と同じ考え方）
- メモはこの PC の `%APPDATA%\Bantus\settings.json` にだけ入り、どこにも送らない。ログにも出さない
- `ColorState` に `'held'` を足し、`DEFAULT_STATUS_COLORS.held = '#e05aa8'`。保存されている色に `held` がなければ既定の色にする（今の `normalizeStatusColors` のままで足りる）

## 決めておきたいこと
- 動き出したら外すか、外さずに「保留（処理中）」として残すか。上では外すことにした（ピンクの意味を「今は止めている」の 1 つに保つため）
- 保留が長くなったときの目印（例：7 日を過ぎたら経過を太字にする）は、使ってみてから決める。経過は札に出ている
- アイコンの押し間違い（開くつもりで保留にしてしまう）が多いようなら、押す的を狭めるか、乗せてから少し（0.3 秒）待たないと切り替わらないようにする
